## 原文

前一段时间 X 上有一场很有意思的讨论，起因是一个叫 Roman 的开发者发了一条推文，说 vibe coding 已经死了。他本来以为 AI 能让大家轻轻松松写代码，结果发现自己变成了“架构官僚”，每天的工作就是写规则、定边界、审代码。如果你不强迫症一样地审查 AI 写出来的每一行代码，项目迟早会崩。

这条推文获得了两千多个赞，引发了大量讨论。其中 Box 的 CEO Aaron Levie 的回复写得最透彻，值得拿出来好好聊聊。

### 工作没有消失，只是往上挪了一层

Levie 的核心观点就一句话：当你让 Agent 替你干活的时候，工作只是移到了更高一层的抽象上。

这话听起来有点绕，但拆开来看就很清楚了。以前你的工作是亲手把事情做出来，现在你的工作变成了一整套新的流程：想清楚让 Agent 干什么，确保给它的指令足够准确，把它需要的上下文喂给它，盯着它别跑偏，审核它交出来的成果，再把这个成果整合到别的地方去。

这里面任何一个环节出了问题，Agent 交出来的东西就是废品。Levie 用了一个很形象的词：poof，一下子就没了，白干。

很多人在用 AI 的时候有一个幻觉，觉得把任务扔给它就完事了。但实际操作过的人都知道，你省下来的执行时间，很大一部分被规划和审核的时间吃掉了。而且任务越复杂、周期越长，规划和审核占的比重就越大。

### 你的新角色：编辑、经理、制片人

Levie 给了一个很精准的角色定义：你现在是编辑，是经理，是制片人。

这三个角色有一个共同点，就是它们都不亲自动手做具体的事情，但它们决定了最终产出的质量。一个好编辑不会自己写稿子，但他能把一篇平庸的稿子改成一篇好稿子。一个好制片人不会自己拍电影，但他能确保整个项目朝着正确的方向走。

Levie 特别强调了三个词：taste（品位）、craft（手艺）、skills（技能）。这三样东西在 Agent 时代不但没有贬值，反而变得更值钱了。因为当执行变得廉价的时候，能判断什么是好的、什么是差的，这个能力就成了稀缺资源。

这个观点其实跟我们日常的经验是吻合的。你让 AI 写一篇文章，它三十秒就能交出来，但你得花十分钟去判断哪些地方写得好、哪些地方需要改、改成什么样才对。这十分钟的判断力，才是你真正的价值所在。

### 瓶颈从执行速度转移到了意图质量

评论区有一条回复写得特别精炼：瓶颈从执行速度转移到了意图的质量。

这句话值得反复品味。过去我们的瓶颈是手速不够快、工具不够好、人手不够多。现在这些问题 AI 都能帮你解决，但新的瓶颈出现了：你到底想要什么？你能不能把这个“想要”表达得足够清楚、足够精确？

有人在评论里说得更直白：如果你脑子不清楚，AI 只会让你的工作量变得更大。Agent 看起来是捷径，但前提是你在动手之前就已经想明白了。

这个道理在企业场景里更加明显。有人提到，在企业里让 Agent 执行任务，难的地方在于 Agent 需要知道你们公司的特殊规则和例外情况，而不仅仅是通用的工作流程。能把这些隐性知识梳理清楚并且表达出来的人，才是真正有价值的人。

### 管理 Agent 的开销本身就是新的核心技能

评论区还有一条来自实战一线的分享特别有价值。一个叫 PMtheBuilder 的用户说，他们公司现在跑着 16 个 Agent，最大的收获是意识到“管理 Agent 的开销”本身就是新的产品技能。写上下文文档、搭建评估关卡、设计交接链路，这些看起来像行政负担的事情，其实就是新时代的核心能力。

这个观察很深刻。很多人觉得用 AI 就应该越来越轻松，但实际上，用好 AI 需要一套全新的管理能力。你得像管理一个团队一样管理你的 Agent：给它们明确的职责边界，给它们足够的背景信息，设计好它们之间的协作流程，还得有一套机制来检验它们的产出质量。

这跟管理真人团队其实很像，只不过沟通的方式从开会变成了写 prompt 和搭系统。

### Vibe coding 的幻灭与真相

回到最初引发这场讨论的那条推文。Roman 说 vibe coding 死了，这个判断可能有点绝对，但他指出的问题是真实的。

Vibe coding 这个概念被很多自媒体包装成了一种魔法：只要你会跟 ChatGPT 聊天，你就能成为开发者。大量的标题党内容让人以为 AI 编程是零门槛的事情。但实际上，一个好的开发者用 AI 编程能如虎添翼，一个不懂开发的人用 AI 编程就像在赌博，有时候赌赢了，大部分时候赌输了。

评论区有人补充了一个更底层的问题：Agent 不是确定性的。传统代码你写什么它就执行什么，但 Agent 有两个失败点，一个是你的指令可能不够清楚，另一个是 Agent 本身的不确定性可能让结果偏离预期。这两个问题叠加在一起，就意味着你必须投入大量精力在审核和纠偏上。

### 工作变多了，但能做到的事情也多了

评论区还有一个很真实的声音。一个叫 Tim 的用户说：工作变多了吗？确实变多了。但那是因为我能做到的事情也变多了。以前从 SEO 深度研究到竞品分析到工具改造再到数据导出，这一整套流程不可能在 5 个小时内完成。现在可以了。虽然累得要死，但确实做到了。

这可能是对 Levie 那段话最好的注脚。AI 没有让工作消失，也没有让工作变轻松。它让工作变了个样子：烦人的重复劳动被自动化掉了，留下来的是更有趣但也更烧脑的部分。你的天花板被抬高了，但你也得付出对应的脑力去够到那个新的天花板。

说到底，Agent 时代最值钱的东西，可能就是 Levie 说的那三个词：品位、手艺、技能。AI 越强大，这三样东西就越稀缺。因为当所有人都能用 AI 生成 80 分的东西时，能看出 80 分和 95 分之间差距的那个人，才是真正不可替代的。

## 批注

* **核心判断**：Agent 没有消灭工作，只是把工作挪到更高抽象层——意图、上下文、纠偏、整合。省下的执行时间，会被规划和审核吃掉；任务越长越复杂，这个比例越高。
* **角色迁移**：编辑 / 经理 / 制片人比「亲手写代码的人」更贴切。执行变廉价后，taste / craft / skills 反而稀缺——能区分 80 分和 95 分，才是不可替代点。
* **新瓶颈**：从执行速度 → 意图质量。脑子不清楚时，AI 只会放大返工；企业场景里，隐性规则与例外的可表达性，才是 Agent 落地的硬门槛。
* **实战信号**：管理 Agent 的开销（上下文文档、评估关卡、交接链路）本身就是产品技能，不是行政负担——和管真人团队同构，只是媒介从开会变成 prompt / 系统。
* **对 vibe coding 的校准**：零门槛叙事是幻灭源；有判断力的人用 AI 如虎添翼，无判断力则像赌博。Agent 双失败点（指令不清 + 模型不确定）决定了审核不可省略。
* **待验证**：自己日常用 Agent 时，规划和审核各占多少时间？哪些环节已经有「评估关卡」，哪些还在靠临时感觉？
